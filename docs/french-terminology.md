# French interface terminology

The interface uses Canadian French. Product names (Searcher, Designer, Collector, Analyzer, Validator) remain names; actions and descriptions are translated. The public Searcher interface can be French while its indexed variable records remain English until the French corpus is indexed.

| English concept | French interface term | Reference |
| --- | --- | --- |
| survey | enquête | [Statistics Canada statistical glossary](https://www150.statcan.gc.ca/n1/edu/power-pouvoir/glossary-glossaire/5214842-fra.htm) |
| questionnaire | questionnaire | [Statistics Canada questionnaire design guide](https://www150.statcan.gc.ca/n1/edu/power-pouvoir/ch2/questionnaires/5214775-fra.htm) |
| respondent | répondant / répondante | [Statistics Canada survey methods](https://www.statcan.gc.ca/fr/produits-services-personnalises/enquetes-personnalisees/questions-a-poser) |
| data collection | collecte de données | [Statistics Canada survey methods](https://www.statcan.gc.ca/fr/produits-services-personnalises/enquetes-personnalisees/questions-a-poser) |
| data dictionary | dictionnaire de données | [Government of Canada TERMIUM Plus](https://www.btb.termiumplus.gc.ca/tpv2alpha/alpha-eng.html?i=&index=alt&lang=eng&srchtxt=DICTIONNAIRE+DONNEES) |
| paradata | paradonnées | [Statistics Canada explanation of paradata](https://www.statcan.gc.ca/fr/a-propos/transparence/lois-reglements/obligation-rendre-compte/partage-donnees/organismes-destinataires-obligations-devoirs) |
| derived variable | variable dérivée | [Statistics Canada derived-variable documentation](https://www.statcan.gc.ca/fr/programmes-statistiques/document/3236_D4_T9_V1-fra.pdf) |

Do not translate survey names or variable labels mechanically. Prefer the official bilingual metadata where available, and identify an English-only record in the French interface.
